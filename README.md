# SWYNEX - AI Problem Design

## Project Title
AI-Based Student Support Question Classifier

## 1. Problem Definition
University students often have difficulty finding information about exams, grades, class schedules, and technical support.

This project aims to develop an AI-based system that automatically classifies student questions into different categories.

## 2. Target Users
University students who need quick access to academic and technical support.

## 3. Data Source
The project will use a dataset of 100 sample student questions.

The dataset will contain five categories:
- Exams
- Grades
- Class Schedules
- University Services
- Technical Support

The questions will be synthetically generated without using personal information.

## 4. AI Use Case
Natural Language Processing (NLP) and Text Classification.

The system will analyze a student's question and predict its category.

## 5. Constraints
- Small dataset.
- No personal or confidential information.
- Five predefined categories.
- Possible ambiguity in student questions.

## 6. Success Criteria
The project aims to achieve:
- At least 80% classification accuracy.
- Balanced performance across categories.
- Reliable predictions on unseen questions.

## 7. Evaluation Approach
The dataset will be divided into:
- 80% training data.
- 20% testing data.

Evaluation metrics:
- Accuracy
- Precision
- Recall
- Macro F1-score
- Confusion Matrix

## 8. Expected Outcome
A simple AI-powered classification system that helps organize student questions and demonstrates the practical use of machine learning in university support services.
